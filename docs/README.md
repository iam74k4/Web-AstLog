# docs

| ファイル | 中身 |
| --- | --- |
| [screens.md](./screens.md) | 画面一覧。どの URL が何を出し、誰が入れるか |
| [flow.md](./flow.md) | 画面遷移図。公開側の導線と、管理側の追加・編集・削除の流れ |

置き場所の使い分け:

- **`docs/`** — 画面と導線。「どんな画面があるか」を知りたいとき
- **`../README.md`** — 構成と動かし方。「どう動かすか」を知りたいとき
- **`../CLAUDE.md`** — 書き方の約束。「どう書くか」で迷ったとき

画面を足したり URL を変えたりしたら、ここも直す。実装とずれた図は、無いより
たちが悪い。
