# 画面一覧

公開が 4 画面、管理が 12 画面。ルートの実体は `src/routes/public.tsx` と
`src/routes/admin.tsx`。

## 公開側

誰でも見られる。出すのは `published = 1` の行だけ。骨格・色・書体は、管理の
[見た目](#見た目)で選んだものがそのまま全ページに効く。

| 画面 | パス | 出すもの | 中身が無いとき |
| --- | --- | --- | --- |
| トップ | `GET /` | 管理の「構成」で置いたブロックを、置いた順に | その節ごと出さない。見出しだけ残さない |
| メンバー個別 | `GET /members/:slug` | Hero → About（紹介文・スキル・経歴）→ Apps·Works への帯 → Contact | 下書きのメンバーは 404 |
| 画像 | `GET /images/avatars/…` | KV に入れたアバター | 該当なしは 404 |
| 404 / 500 | 未定義の URL / 例外 | マークと戻り導線だけ | — |

### トップの構成

トップは「決まった部品（ブロック）の積み重ね」で、管理の[構成](#構成)から
置く・外す・上下に動かす。部品の見た目は変えられないので、どう並べても同じ設計の
中に収まる。何も置いていなければ Hero → Apps → Works → Team → Contact の順。

| ブロック | 中身 | 出す条件 | 備考 |
| --- | --- | --- | --- |
| Hero | 大見出しとリード（`src/site.ts`） | 常に | 目次には載らない |
| Apps | 公開中の app | 1件以上 | 絞り込みピルは、実在するプラットフォームだけ並ぶ |
| Works | 公開中の work | 1件以上 | 実績値は1項目に1つだけ |
| Team | 公開中のメンバー | 1人以上 | **1〜2人は横長カード、3人以上はグリッド**。人数で決める、画面幅では決めない |
| Contact | 連絡先（`src/site.ts`） | 常に | |
| ひとこと | 大きな一文と添え書き（段落は何段でも） | 一文がある | 目次には載らない |
| いま | 「何を \| 補足」の箇条書き | 1行以上 | |
| 数字 | 「値 \| 単位 \| 説明」のタイル | 1行以上 | 2〜4つが収まりがよい |
| リンク集 | 「ラベル \| URL \| 補足」 | 有効な URL が1行以上 | `https://` `mailto:` `/` 以外は落とす。`//host` は外部 URL なので通さない |
| できごと | 「年月 \| 何を \| 補足」 | 1行以上 | 個人ページの経歴と同じ形 |
| メモ | 段落の文章 | 1段落以上 | 見出しは無くてもよい。無ければ目次にも載らない |

上の5つは1つずつしか置けない。下の6つはいくつでも置ける。
目次（左の 01〜）は、実際に出た節だけを、出た順に載せる。

### メンバー個別ページ

- Apps / Works のカードはここに複製しない。帯から
  `/?member=<slug>#apps` へ送り、トップの一覧をその人で絞り込んだ状態にする
- 担当する公開項目が0件なら、帯ごと出さない

## 管理側

`/admin/*`。ログインが要る。書き込みは `Origin` も確認する（ログイン画面を含む）。

| 画面 | パス | 認証 | 役割 |
| --- | --- | --- | --- |
| 入口 | `GET /admin` | 要 | `/admin/members` へ 303 |
| ログイン | `GET /admin/login` | 不要 | フォーム |
| ログイン実行 | `POST /admin/login` | 不要 | 成功で Cookie を発行し `/admin/members` へ |
| ログアウト | `POST /admin/logout` | 要 | セッションを消す |
| 初期設定 | `GET`/`POST /admin/setup` | 不要 | **users が空で、かつ `SETUP_TOKEN` が一致するときだけ**。owner を1件作る。以降は 404 |
| Members 一覧 | `GET /admin/members` | 要 | 行に 公開/下書き・並び順・編集・削除 |
| Member フォーム | `GET /admin/members/new`<br>`GET /admin/members/:id/edit` | 要 | 追加と編集で同じテンプレート |
| Member 保存 | `POST /admin/members`<br>`POST /admin/members/:id` | 要 | 成功で `?saved=1` を付けて一覧へ |
| Member 削除 | `GET /admin/members/:id/delete`（確認）<br>`POST` 同 URL（実行） | 要 | 確認画面を必ず挟む |
| Items 一覧 | `GET /admin/items?type=app\|work` | 要 | Apps / Works をタブで切り替え |
| Item フォーム | `GET /admin/items/new?type=…`<br>`GET /admin/items/:id/edit` | 要 | `type` で欄が変わる（app はプラットフォーム、work は区分と実績値） |
| Item 保存 | `POST /admin/items`<br>`POST /admin/items/:id` | 要 | タグとリンクは総入れ替え |
| Item 削除 | `GET /admin/items/:id/delete`（確認）<br>`POST` 同 URL（実行） | 要 | 一緒に消えるタグ・リンクの件数を出す |
| 構成 | `GET /admin/blocks` | 要 | トップの並び。行ごとに ↑↓・公開/下書き・編集・外す。下に「足す」のカタログ |
| ブロック追加 | `POST /admin/blocks`（決まった中身のもの）<br>`GET /admin/blocks/new?type=…` → `POST /admin/blocks`（打ち込むもの） | 要 | 一番下に足される |
| ブロックフォーム | `GET /admin/blocks/:id/edit`<br>`POST /admin/blocks/:id` | 要 | 決まった中身のものは「公開する」だけ |
| ブロック移動 | `POST /admin/blocks/:id/move`（`dir=up\|down`） | 要 | 並び順を 10 刻みで振り直す |
| 既定の並び | `POST /admin/blocks/init` | 要 | 何も置いていないときだけ5つを入れる |
| ブロック削除 | `GET /admin/blocks/:id/delete`（確認）<br>`POST` 同 URL（実行） | 要 | 決まった中身のものは、外しても登録した項目は消えない |
| 見た目 | `GET /admin/appearance`<br>`POST` 同 URL（保存） | 要 | 骨格・アクセント色・書体を選ぶ。サイト全体に効く |

一覧・フォーム・確認の3種類だけで、Members・Items・構成をまかなっている。
一覧にフォームを同居させないのは、「どの行を編集中か」が読めなくなるため。
見た目だけは一覧を持たない。選ぶものが3つで、増えも減りもしないため。

### 構成

トップに置くブロックの一覧。行の ↑↓ はそれぞれ小さな `POST` フォームで、押すと
303 で同じ一覧に戻る（JavaScript は使わない）。

- 何も置いていないときは、既定の並びで出している旨と「この並びから始める」だけを出す。
  **「足す」はまだ出さない**。今そこに見えている5節は既定の並びで、行としては
  存在しない。先にそれを行にしてから触らせる
- 「足す」には、まだ置いていない決まった中身のもの＋打ち込むもの全種が並ぶ。
  決まった中身のものは押せばすぐ置かれ、打ち込むものはフォームへ進む
- 「外す」は確認を挟む。決まった中身のもの（Apps など）を外しても登録は消えない。
  `blocks.ts` から消えた種類の行も外せる（読む側が無視するだけでは、一覧に残り続ける）

### 見た目

サイト全体の姿を、決め打ちの組み合わせから選ぶ。1画面で3つを選び、保存すると
すぐ公開ページに出る（下書きは無い）。

| 選ぶもの | 選択肢 | 効く場所 |
| --- | --- | --- |
| 骨格 | 左サイドバー / 中央寄せ / 雑誌風 | ページの組み立て方。狭い画面ではどれも1列に畳む |
| アクセント色 | アイリス / エンバー / ミント / スカイ / ローズ | リンク・選択中の印・実績値 |
| 書体 | ゴシック / 明朝 / 等幅 | 見出しだけ。本文は読みやすさを優先して据え置く |

選べる値は `src/theme.ts` が正。実際に姿を変えるのは `public/app.css` の
`[data-layout]` などで、**両方に足さないと「選べるのに何も変わらない」ものができる**。
保存済みの値が選択肢から消えていたら、既定（左サイドバー・アイリス・ゴシック）で描く。

## 画面の状態

どれも JavaScript なしで、1往復で成立する。

| 状態 | 出る場所 | 出し方 |
| --- | --- | --- |
| 入力エラー | フォーム | 項目のそばに1行。**打った内容は残す** |
| ログイン失敗 | ログイン | 「メールアドレスかパスワードが違います」。どちらが違うかは言わない |
| 試行回数の制限 | ログイン | 5回失敗で 15 分。429 を返す |
| 一覧が空 | 管理の一覧 | 空の表を出さず、「＋ 最初の…を追加」だけ置く |
| 絞り込みで0件 | トップの Apps | ピルは残し、1行だけ出す |
| 保存完了 | 一覧・構成・見た目 | `?saved=1` を読んで帯を1回だけ |
| 置けないブロック | 構成 | 400。同じ種類を2つ置こうとしたとき、知らない種類のとき、動かす向きが不明なとき |
| 出せない中身 | ブロックフォーム | 400。リンク集は URL の形まで見る（「公開」なのに出ない行を作らない） |
| 選べない見た目 | 見た目 | 400。帯を1本出し、保存はしない |
| 削除の確認 | 削除確認 | 対象名と、一緒に消えるものの件数。「非公開にする」逃げ道も添える |
